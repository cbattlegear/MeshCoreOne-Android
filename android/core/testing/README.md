# WP-004 independent test support

This is a **test-only Android library**, never a production dependency. Its
Kotlin helpers are Android-free; its current artifact is an Android AAR, not a
new shared JVM fixture module. `validateModuleGraph` enforces that production
configurations cannot depend on it. JVM protocol WPs can consume the independent
files in `fixtures/`; moving common helper code into a JVM fixture module needs
the owning build/architecture amendment, not a speculative module here.

`TestClock` follows both pinned Swift helpers: virtual time changes only through
`advanceBy`, due sleepers resume outside the lock, past deadlines return
immediately, and cancellation removes parked continuations. `SchedulerClock`
uses the calling coroutine test scheduler. `waitUntil` requires an injected
clock, preserves the 10-second/10-millisecond defaults and final deadline check,
and propagates condition errors/cancellation. `CallTracker` uses a 64-bit atomic
count. `MutableBox` makes individual value reads/writes atomic, not compound
read-modify-write operations.

`TestFixtureContainer` assembles a scheduler, dispatcher, clock and **owned test
scope only**. `ScriptedOperation`/`RecordedCalls` are primitive callback/repository
controls: missing results and unconsumed scripts fail explicitly. These are not
`MeshTransport`, DTOs, Room repositories, `AppContainer.forTesting()` or a pretend
radio graph. The merged scaffold's real in-memory Room verification remains
separate; actual model/database/service assembly belongs to WP-201/202/303.

## Executable commands

`:core:testing:testDebugUnitTest` runs in hosted CI (`.github/workflows/android-ci.yml`). Locally, from `android/`:

```powershell
./gradlew :core:testing:testDebugUnitTest validateModuleGraph --dependency-verification strict
python ../tools/android-port/extract_vectors.py --check
```

These are executed JVM helper/fixture assertions in an Android module, not API31/37 instrumentation, radio
hardware or app parity.

## Frozen inputs and generation

The source stays read-only at
`db14559b39d32322b06477c6ae676112f583db50`. `tools/android-port/extract_vectors.py` has an explicit
`--regenerate` mode; check mode never updates expectations. Unknown paths, renames, changed source
bytes/blobs, malformed syntax/families and missing/zero evidence fail. Git text CRLF/LF checkout
normalization is allowed, not source changes.
`fixtures/protocol-vectors.json` copies all 37 pinned `PythonReferenceBytes`
fields and 12 explicit Swift endian/high-bit/truncation/frame literals. Every
vector retains byte count/digest, protocol snapshot, field and full source/blob/
case-assertion provenance. The TSV is the same independently copied bytes for
strict Kotlin fixture consumption, included in test resources only. No expected
packet is generated by candidate Kotlin.

`fixtures/reference-codec/` contains actual macOS-run Swift exports, independent
crypto bytes and the complete source map/evidence from run37167976130 at
6e22d476. The test-only JVM probe consumes the exact compressed Swift bytes using
the observed raw-deflate container and compares them with the exact Swift JSON
export; it is not an Android DTO/backup/transactional-restore implementation.

The exact-source Swift oracle is `tools/android-port/oracle/codec_harness.py`; hosted CI reruns it on macOS
(`swift-codec-oracle`). GPLv3 application and MIT MeshCore notices remain authoritative; fixture and
oracle evidence does not approve new dependencies, signing or release licenses.
