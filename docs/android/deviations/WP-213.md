## A-01: shared shape

Main-actor state becomes state behind the coordinator lock. Nothing suspends
while holding it, and background work runs on an injected scope that must
dispatch rather than run inline. Background jobs hold the coordinator strongly
until they finish or are cancelled. Observation goes through `StateFlow`, which
skips re-emitting a value equal to the current one. DEBUG-only seams are always
compiled in.

- **Writers:** a writer's staleness check and the write it guards run as one
  locked step (`ifWriterGeneration`). A stale writer on another thread can't
  overwrite the open chat.
- **Callbacks:** Swift's view-model callbacks cannot throw. A throwing
  `renderItemRebuilder`, `renderStateInvalidated` or `postApply` is logged and
  contained. It doesn't skip the rest of a reload batch or fail the shared
  scope.
- **Superseded builds:** a build replaced by a newer `rebuildItems` exits
  silently under the lock, as Swift's cancelled task does. It never fires
  `renderStateInvalidated`.
- **Cancellation:** a cancelled reload drain stops. Swift swallows the error and
  continues. A caller cancelled while waiting its turn on the window lane throws
  instead of starting its operation, and the queue order is kept.
- **Store keys:** store calls use `EntityKey(radioId, id)` where Swift passes a
  bare UUID.

## A-02: text semantics

Expected values for these were printed by the frozen Swift compiled with the
local toolchain, not written by hand.

- **Self-mention case comparison:** Foundation's `caseInsensitiveCompare` is
  reproduced with Foundation's own per-scalar folding table, generated by
  `docs/android/evidence/WP-213/foundation-casefold/`, over canonical
  decompositions. It keeps Turkish `ı` distinct from `i`, and folds `ẞ`/`ß` to
  `ss`, ligatures and Greek final sigma, as iOS does. Foundation's comparison is
  not a pure fold, so a few rare forms still differ: iota-subscript Greek, `ŉ`,
  `ẚ` and historic Cyrillic variants such as U+1C80.
- **Graphemes:** JDK 21 lacks one Unicode 15.1 rule, so a Devanagari-style
  conjunct counts as 2 characters instead of 1. A test pins this. It only
  affects the 10-character reply preview.
- **Emoji:** `isEmoji` uses a table taken from the Swift runtime, including 14
  newer emoji the JDK doesn't know.
- **Case mapping:** lowercasing for scripts newer than Unicode 15 follows JDK
  data.
- **String equality:** rendering models compare code units, consistent with the
  existing `MessageDTO`. Canonical equivalence is applied only where it changes
  a decision: LRU sender keys, avatar lookup, self-mention matching and
  character comparisons.
- **Search and sort:** contact filtering and sorting use the JDK collator, which
  matched Swift on every tested US-English case but isn't guaranteed identical.
- **URLs:** `WebURL.parse` rejects what `java.net.URI` rejects. Since iOS 17,
  Swift repairs some of those inputs instead (`"hello world"` →
  `hello%20world`).
- **Smaller differences:** the avatar revision is a SHA-256 prefix rather than
  Swift's per-process hash. The `"und"` locale gives `"en"`. A negative registry
  capacity is rejected where Swift crashes. Double-carrying rendering values use
  Swift equality, so −0.0 equals 0.0 and NaN is never equal.

## Test adaptations

- **ChatRenderStateTests:** existing core snapshot smoke predicates are retained.
  Their historical coordinator-to-own-flow comparison does not establish mounted
  accessor parity; the actual five-field oracle is in `SharedTimelineIntegrationTest`.
- **InlineImageDimensionsStoreTests:** the store belongs to WP-218. A reference
  historical test double runs 9 cases and checks the builder aspect boundary.
  `content/InlineImageDimensionsStoreTest` exercises the real landed store and its
  registration, independent overflow, cancellation, reentrant completion and finish.
- **Offline registry:** the case no longer saves a contact, because contact
  saving isn't part of `MessagePersisting`.
- **Owner deallocation:** explicit close/release is the deterministic native
  ownership contract. Forced-GC polling was removed; mounted sibling and suspended
  paging cases prove release and successor isolation without assuming ARC.
- **No sleep polling:** Swift's sleep loops become joins on the background job.
- **Footprint hashes:** Swift's hash values change every process, so the cases
  compare inequality, as Swift does.
