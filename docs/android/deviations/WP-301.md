## Evidence limits

Actual outcomes and raw source-family/JUnit/render evidence belong in
[WP-301 evidence](../evidence/WP-301/README.md). Header/file inventory is not
parity. A static inventory of 55 mapped and three approved removed families
does not mean native tests have run. Native PNGs are captured from an actual
Robolectric Compose host, asserted nonblank, and retained with complete bytes,
dimensions and hashes inside the existing verbatim module JUnit artifact.
They are new execution evidence, not updated screenshot goldens.

No Swift/UIKit execution, physical API31/37 device, TalkBack session, wide-gamut
display hardware, radio/HIL, TEE, signing/release, formal license acceptance or
complete application graph is asserted by this WP.

The actual SDK37 Espresso/Compose runner invokes removed
`InputManager.getInstance()` and failed before the case ran. The production
public contrast-subscription adapter is therefore exercised directly on
simulated SDK37, with listener delivery/removal/late-callback assertions;
actual Compose environment/disposal is exercised on SDK31. No hidden API shim
or proxy claim of SDK37 Compose execution was introduced. PixelCopy capture
also timed out on the actual native Robolectric host: captures now draw the
real attached Android/Compose view into a NATIVE graphics bitmap, assert
nonblank pixels, and retain exact bytes/hash/dimensions. These are rendered
view evidence, not synthetic palette pictures or updated expectations.

Selected theme cards remain non-actionable, as in the source, but their
disabled Material content colors explicitly retain the accessible on-surface
role rather than the component's low-alpha disabled default. The batched
native inspection found that issue; the coherent fix and one confirmation
retain all source palettes and selected semantics.

Independent source review found three additional correctness defects at the
earlier native head. Outgoing identity/mention ranges must use the outgoing
base foreground (the frozen normalizer's outgoing branch), not an identity

expected terminal `false`, while caller cancellation still propagates before

are being added before any expectation or production change. Prior 87/39
evidence is not silently relabeled.
